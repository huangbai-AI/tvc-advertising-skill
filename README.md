# TVC Skill

上传一张瓶装茶饮或即饮饮料产品图，即可生成一支约 18 秒、16:9、真人电影级的公园野餐 TVC 提示词。

这个 Skill 以“人已在户外，注意力仍在线上”为情绪起点，通过真实落叶、包装角色、冷凝水珠、饮用动作和朋友互动，让主角自然回到当下。产品图负责锁定瓶型、材质、标签、文字、液体颜色与包装元素；Skill 负责镜头、时间线、声音、连续性和限制条件。

## 适用场景

- 无糖茶、绿茶、乌龙茶、气泡水、果味水等瓶装即饮产品。
- 需要年轻、自然、清透、轻松的生活方式广告。
- 希望包装角色或包装视觉元素参与叙事，但不做魔法、霓虹或高饱和卡通效果。
- 需要 Seedance 等视频模型可直接使用的结构化中文提示词。

## 使用方法

把产品图上传到对话，然后调用：

```text
使用 $picnic-product-tvc，根据我上传的产品图生成一支 18 秒公园野餐 TVC。
保留产品包装与文字，主角换成 25 岁左右中国女性，结尾文案是“这一刻，轻一点。”
```

如果产品没有包装角色，Skill 不会擅自创造吉祥物，而会使用落叶、冷凝水珠、瓶盖动作、人物视线和形状匹配完成转场。

## 生成内容

- 主体：人物、朋友、产品、场地、固定道具和情绪变化。
- 风格：画幅、时长、摄影质感、色彩、光线与镜头语言。
- 时间线：从手机分心、产品介入、饮用、液体微距到产品英雄镜头。
- BGM 与声音：音乐结构、环境声、瓶盖声、吞咽声和旁白。
- 限制：人物、产品、标签、瓶盖、液位、手部、文字与品牌连续性。

## 安装

解压后，将 `picnic-product-tvc` 文件夹复制到 Codex skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R picnic-product-tvc ~/.codex/skills/
```

重新打开 Codex 后，通过 `$picnic-product-tvc` 调用。

## 设计原则

- 产品只有一件，包装、标签、瓶盖、液位和冷凝水全程连续。
- 情绪与色彩逐步打开，不通过突然换天气或切场景完成。
- 包装角色必须来源明确，始终只有一个，并遵守真实表面和遮挡关系。
- 不使用光带、能量线、速度线或魔法粒子作为转场捷径。
- 不杜撰功效、营养、环保或其他商业宣称。
